# InboxPilot 项目状态与验收记录

## 当前状态

阶段一至阶段四已经全部完成。InboxPilot 当前可视为一个功能闭环、可在个人电脑长期运行的完整 MVP，并覆盖以下完整链路：

```text
发现新邮件 → 规则 / 可选 LLM 分析 → 可解释优先级 → 人工复核
→ 受控写回与回滚 → 通知、审计、诊断和恢复 → 全新环境部署
```

当前自动化质量基线为 441 项测试通过，覆盖率 84.83%，Ruff 和 mypy 通过。真实邮件、Token、API Key、私有队列和审计日志均由 Git 忽略。

## 真实 Outlook 验收

2026-08-09 至 2026-08-10，在个人 Outlook 测试环境中完成：

- 单封邮件分类写入和真实受控回滚；
- 3 封邮件逐封正向写入和逐封回滚清理；
- 每个动作均为一次 GET、最多一次 PATCH、零自动重试；
- 用户自有分类得到保留；
- 邮件位置、主题、正文和附件状态保持不变；
- 新到达邮件被只读同步、分析并生成待确认动作；
- 自动工作流 Graph 写请求始终为 0；
- 人工批准后，受控执行器成功写入对应 Outlook 分类；
- 重复同步产生零新增分析、零重复提醒和零 Graph 写请求。

## 当前限制与后续方向

- 目前主要面向中文高校邮件和个人 Outlook 收件箱；
- 尚未验证组织租户策略、共享邮箱和其他邮件文件夹；
- 50 封公开样例和当前真实验收不能代表所有邮箱的泛化效果；
- 当前没有操作系统开机自启或无人确认的自动批量写回；
- HTMX 使用带 SRI 的固定 CDN 版本，完全离线时增强交互可能不可用；
- 后续可增加 GitHub Actions、完全本地静态资源、Web 演示和更大规模的匿名真实场景评测。
